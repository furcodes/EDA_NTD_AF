# Glimpse on Neglected Tropical Diseases (NTDs) through glabal stats

---
AF - November 2026

This is an EDA project uploaded as part of a Data Science bootcamp.

## Tackling Neglected Tropical Diseases has been one of the major goals set by WHO. 

Research on drug discovery against these diseases are usually known to be underfunded while therapeutic options available are scarce. 

This Exploratory Data Analysis aims to have an overview on the past and current state of NTDs interventions needed at a global stage.
The next steps to be followed shall explore the microorganisms, antimicrobials involved but most of all try to understand the problem at hand from the AMR 2050 standpoint.

In this repo, the reader shall find a notebook, data folder with the datasets used and an image folder with the plots generated throughout this EDA.
A presentation written in marp is also uploaded.
Please note ,the notebook and other materials are meant to be updated.
